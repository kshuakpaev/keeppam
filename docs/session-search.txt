# KeepPAM: forensic-поиск по сессиям

Поиск по `session_events`: SQL, kubectl, **команды SSH**, **вывод SSH**, **клавиши RDP/VNC**, JEA deny, DLP, risk, HTTP/object ACL, **SSH egress**.

SSH: живой line-buffer (JEA / `max_risk>0`) пишет `command` сразу. Сессии без буфера — индекс stdin из asciicast v2 при конце сессии или кнопкой в replay. **Stdout** (`o`) индексируется тем же проходом в тип `output`; при `pii_action` mask/deny — те же PII-паттерны (`docs/dlp.txt`). Имена файлов SCP/SFTP — тип `file_transfer`.

RDP/VNC/isolated: `recording-include-keys` → `keystroke`. OCR кадра → `screen_text` (`docs/ocr-rdp.txt`, не полное видео).

Лента «все действия пользователя за день» — `docs/forensic.txt`.

## API

`GET /api/v1/admin/sessions/events` (`sessions.read`)

| Query | Смысл |
|-------|--------|
| `q` | подстрока в payload / event_type (ILIKE, экранирование `%_`) |
| `type` | пусто = forensic (`sql`, …, `output`, `keystroke`, `screen_text`, `dlp`, …); `all` = любые; иначе точный тип |
| `hours` | окно, default 168, max 2160 |
| `limit` / `offset` | пагинация |

`GET /api/v1/admin/sessions/{id}/transcript` — команды + `output[]` + `keystrokes[]` + `screen_text[]`.  
`POST .../transcript` `{force?, ocr?}` — asciicast (SSH), `.guac` keys, опционально OCR (RDP/VNC/isolated).

Оператор видит только свои сессии; `audit.read` / `users.write` — все.

Ответ поиска: `{events: [{snippet, type, ts, session_id, username, asset_name, protocol, …}], total}`. Тела Secret/паролей в payload нет (k8s body_redacted). Ввод пароля в PTY и текст с экрана могут попасть в индекс — как и в самой записи.

## UI

Сессии → вкладка **События**. Replay SSH: команды + вывод. Replay RDP/VNC: **Клавиши** + **Экран (OCR)**. Кнопки «Индексировать запись» / «OCR экрана».

## Индекс

До 400 строк stdin/stdout/keystroke / 8 MiB записи; OCR — до 120 `screen_text` (Policy, default 60). Строка ≤ 512 рун.

## Вне scope

OpenSearch-кластер, маскирование паролей в stdin/stdout/клавишах/OCR, live-индекс до конца сессии, полное видео OCR.
