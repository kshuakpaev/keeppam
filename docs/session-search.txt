# KeepPAM: forensic-поиск по сессиям

Поиск по `session_events`: SQL, kubectl, **команды SSH**, **вывод SSH**, **клавиши RDP/VNC**, JEA deny, DLP, risk, HTTP/object ACL, **SSH egress**.

SSH: живой line-buffer (JEA / `max_risk>0`) пишет `command` сразу. Сессии без буфера — индекс stdin из asciicast v2 при конце сессии или кнопкой в replay. **Stdout** (`o`) индексируется тем же проходом в тип `output`; при `pii_action` mask/deny — те же PII-паттерны (`docs/dlp.txt`). Имена файлов SCP/SFTP — тип `file_transfer`.

RDP/VNC/isolated: `recording-include-keys` → `keystroke`. OCR кадра → `screen_text` (`docs/ocr-rdp.txt`): выборка, **каждый кадр** (до 5/с, cap 3600) и **live** во время сессии. Из OCR/клавиш → `win_process` (`docs/win-proc.txt`, best-effort без агента).

SSH/Telnet **stdout** индексируется live и в конце сессии (`output` + `screen_text` source `ssh_stdout`).

Лента «все действия пользователя за день» — `docs/forensic.txt`.

## API

`GET /api/v1/admin/sessions/events` (`sessions.read`)

| Query | Смысл |
|-------|--------|
| `q` | подстрока в payload / event_type (ILIKE, экранирование `%_`) |
| `filename` | имя/путь `file_transfer` (payload `filename`/`path`); без `type` — только эти события |
| `process` | имя `win_process` (payload `name`); без `type` — только эти события |
| `protocol` | протокол сессии |
| `client_ip` | подстрока `sessions.client_ip` |
| `type` | пусто = forensic (`sql`, …, `file_transfer`); `all` = любые; иначе точный тип |
| `hours` | окно, default 168, max 2160 |
| `limit` / `offset` | пагинация |

`GET /api/v1/admin/sessions/{id}/transcript` — команды + `output[]` + `keystrokes[]` + `screen_text[]` + `processes[]` (RDP/VNC).  
`POST .../transcript` `{force?, ocr?}` — asciicast (SSH), `.guac` keys, опционально OCR (RDP/VNC/isolated).

Оператор видит только свои сессии; `audit.read` / `users.write` — все.

Ответ поиска: `{events: [{snippet, type, ts, session_id, username, asset_name, protocol, …}], total}`. Тела Secret/паролей в payload нет (k8s body_redacted). Ввод пароля в PTY и текст с экрана могут попасть в индекс — как и в самой записи.

## UI

Сессии → вкладка **События**: тип, имя файла, **процесс**, протокол, IP. Replay SSH: команды + вывод + **файлы** (клик — seek по offset). Replay RDP/VNC: клавиши + OCR + **окна** + **процессы** (первая строка кадра / Task Manager). Скорость SSH 1×/2×/4×.

## Индекс

До 400 строк stdin / **4000** stdout / 8 MiB записи; OCR — до **3600** `screen_text` (Policy, default 60). Строка ≤ 512 рун. Live-индекс до конца сессии: Policy `ocr_live` / `ocr_ssh_stdout`.

## Вне scope

OpenSearch-кластер, маскирование паролей в stdin/stdout/клавишах/OCR, OCR в compliance PDF.
