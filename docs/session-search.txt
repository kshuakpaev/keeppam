# KeepPAM: forensic-поиск по сессиям

Поиск по `session_events`: SQL, kubectl, **команды SSH**, JEA deny, DLP, risk, HTTP/object ACL, **SSH egress**.

SSH: живой line-buffer (JEA / `max_risk>0`) пишет `command` сразу. Сессии без буфера — индекс stdin из asciicast v2 при конце сессии или кнопкой в replay (не output, не RDP/видео).

Лента «все действия пользователя за день» — `docs/forensic.txt`.

## API

`GET /api/v1/admin/sessions/events` (`sessions.read`)

| Query | Смысл |
|-------|--------|
| `q` | подстрока в payload / event_type (ILIKE, экранирование `%_`) |
| `type` | пусто = forensic (`sql`, `sql_denied`, `k8s`, `command`, `command_denied`, `command_approval`, `command_approved`, `dlp`, `risk`, `http_denied`, `app_denied`, `app_approval`, `app_approved`, `egress`, `egress_denied`); `all` = любые; иначе точный тип |
| `hours` | окно, default 168, max 2160 |
| `limit` / `offset` | пагинация |

`GET /api/v1/admin/sessions/{id}/transcript` — команды этой сессии.  
`POST .../transcript` `{force?}` — разобрать asciicast (если нет PTY-журнала).

Оператор видит только свои сессии; `audit.read` / `users.write` — все.

Ответ поиска: `{events: [{snippet, type, ts, session_id, username, asset_name, protocol, …}], total}`. Тела Secret/паролей в payload нет (k8s body_redacted). Ввод пароля в PTY может попасть в индекс как строка — как и в самой записи.

## UI

Сессии → вкладка **События**. Replay SSH: список команд + «Индексировать команды».

## Индекс

Миграция `036`: `pg_trgm` GIN на `payload::text`. Миграция `063`: `sessions.transcript_indexed_at`. До 400 строк / 8 MiB записи, строка ≤ 512 рун.

## Вне scope

Полнотекст **вывода** asciicast, OCR/RDP/Guacamole, OpenSearch, маскирование паролей в stdin.
