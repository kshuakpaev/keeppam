# NIT §3 — комплект поставки железа

П. 3 NIT требует **не менее двух новых физических серверов** (год выпуска не ранее 2026) в комплекте поставки, чтобы HA работал с первого дня, и запас **≥30%** к нагрузке п. 4.

Это **не функция ПО**. KeepPAM задаёт профили; стойки, партии и акты «новый / не б/у» оформляет поставщик.

## Что класть в заявку

| Позиция | Значение |
|---------|----------|
| Количество | 2 идентичных хоста (Active-Active control + data plane, или зеркало 2+2) |
| Состояние | новые, не б/у, не refurbished; модификация в производстве |
| Год выпуска | ≥ 2026 |
| Гипервизор | VMware / KVM (Proxmox) — `docs/appliance-ova.txt` |
| ПО с первого дня | HA 2+2 (`docs/ha.txt`) + Postgres HA (`compose.pgha.yml` / CNPG) |

## Характеристики с запасом 30% к п. 4

Ориентир плотности: ~50 смешанных сессий на session-worker 4–8 vCPU (`docs/system-requirements.txt`). Профиль 1000 сессий (SSH-heavy 80/15/5): **20 worker + 8 guacd + 6 API** (`docs/nit-p4.txt`).

Запас 30% → считать **~1300** сессий / **~260** операторов портала.

| На 2 хоста (суммарно, затем пополам) | П. 4 | +30% |
|--------------------------------------|------|------|
| vCPU (workers + guacd + API + PG) | ~300 | **~390** |
| RAM | ~0.6–1 TiB | **~0.8–1.3 TiB** |
| Сеть | 10 Gbit/s к активам и к операторам | 10–25 Gbit/s |
| Recordings | S3/СХД; локальный буфер NVMe **≥ 8 TiB** на пару | +30% буфер |

Практичная нарезка (два одинаковых сервера 2026+):

- **2× CPU** (класс 64–96 ядер / сокет не обязателен — главное суммарно ≥ ~200 ядер на хост при раскладке «каждый хост несёт половину HA»);
- **512–1024 GiB RAM** на хост;
- **NVMe 2× 3.84 TiB+** (ОС/Docker/PG) + отдельный том или СХД под recordings;
- **2× 10/25 GbE**;
- BMC/iLO/iDRAC, Dual PSU.

Точный SKU (Dell/HPE/Lenovo) выбирает поставщик под доступность 2026 года. KeepPAM не продаёт железо.

См. `docs/nit-p4.txt`, `docs/system-requirements.txt`, `docs/ha.txt`.
