# KeepPAM: production infra (mTLS / S3 / KMS)

## Data key (KMS-style provider)

`KEEPPAM_DATA_KEY_SOURCE`:

| Value | Env | Notes |
|-------|-----|-------|
| `env` (default) | `KEEPPAM_DATA_KEY` | base64 of 32 raw bytes (AES-GCM envelope) |
| `file` | `KEEPPAM_DATA_KEY_FILE` | file with base64 text or raw 32 bytes |
| `vault` | `KEEPPAM_VAULT_ADDR`, `KEEPPAM_VAULT_TOKEN`, `KEEPPAM_VAULT_CIPHERTEXT`, optional `KEEPPAM_VAULT_TRANSIT_PATH` | POST transit decrypt; expects `{"data":{"plaintext":"<base64 32 bytes>"}}` |
| `aws` | `KEEPPAM_KMS_CIPHERTEXT`, `KEEPPAM_AWS_ACCESS_KEY`, `KEEPPAM_AWS_SECRET_KEY`, `KEEPPAM_AWS_REGION` | AWS KMS Decrypt (SigV4, без SDK) |
| `gcp` | `KEEPPAM_KMS_CIPHERTEXT`, `KEEPPAM_GCP_KMS_KEY`, token или GCE metadata | Cloud KMS `:decrypt` |
| `azure` | `KEEPPAM_KMS_CIPHERTEXT`, `KEEPPAM_AZURE_VAULT_URL`, `KEEPPAM_AZURE_KEY_NAME`, token или client credentials | Key Vault unwrapkey / decrypt |
| `pkcs11` | `KEEPPAM_PKCS11_TOKEN_FILE` + PIN + `KEEPPAM_KMS_CIPHERTEXT`, или `KEEPPAM_PKCS11_HELPER` | HSM / software token, см. `docs/pkcs11.txt` |

Ключ по-прежнему питает локальный AES-GCM Envelope (секреты учёток / SIEM / SSH CA / audit HMAC). Cloud unwrap — см. `docs/kms.txt`. PKCS#11 — `docs/pkcs11.txt` (`KEEPPAM_DATA_KEY_SOURCE=pkcs11`).

## Recordings store

`KEEPPAM_RECORDINGS_BACKEND=local|s3` (default `local`).

Для `s3` (MinIO / Ceph / AWS path-style):

- `KEEPPAM_S3_ENDPOINT` — например `http://minio:9000`
- `KEEPPAM_S3_BUCKET`
- `KEEPPAM_S3_ACCESS_KEY` / `KEEPPAM_S3_SECRET_KEY`
- `KEEPPAM_S3_REGION` (default `us-east-1`)
- `KEEPPAM_S3_PREFIX` (optional)
- `KEEPPAM_S3_PATH_STYLE` — default true (`false` = virtual-hosted)
- `KEEPPAM_S3_OBJECT_LOCK_MODE` — пусто | `GOVERNANCE` | `COMPLIANCE` (WORM)
- `KEEPPAM_S3_OBJECT_LOCK_DAYS` — retention при Put (default 90)

Bucket должен быть создан с Object Lock enabled (MinIO: `mc mb --with-lock`). Compliance mode нельзя снять до даты; Governance — с bypass permission.

Поведение hybrid: guacd/SSH пишут в `KEEPPAM_RECORDINGS_DIR` как раньше; при закрытии сессии API/worker зеркалит файл в S3 (с Object Lock headers, если mode задан). Replay сначала ищет локально, иначе скачивает из S3. Purge не удаляет WORM-объекты (`skipped_worm`). Legal hold сессии → S3 Legal Hold ON/OFF.

## API TLS / mTLS

- `KEEPPAM_TLS_CERT_FILE` + `KEEPPAM_TLS_KEY_FILE` — HTTPS (`ListenAndServeTLS`)
- `KEEPPAM_TLS_CLIENT_CA_FILE` — проверка клиентского сертификата
- `KEEPPAM_TLS_REQUIRE_CLIENT_CERT=true` — обязательный mTLS; иначе optional (`VerifyClientCertIfGiven`)

SPIFFE (файловый SVID / bundle, без SPIRE в compose) — `docs/spiffe.txt`:

- `KEEPPAM_SPIFFE_TRUST_DOMAIN` — фильтр URI SAN
- `KEEPPAM_SPIFFE_SVID_FILE` + `KEEPPAM_SPIFFE_SVID_KEY_FILE` — identity процесса; если TLS cert пуст, ими слушает HTTPS
- `KEEPPAM_SPIFFE_BUNDLE_FILE` — доп. Client CA

Рекомендуется `KEEPPAM_COOKIE_SECURE=true` при включённом TLS.

## GeoIP (ABAC)

`KEEPPAM_GEOIP_DB` — MaxMind-совместимый Country MMDB (api и session-worker).
Стенд: `deploy/geoip/country-demo.mmdb`. Прод: GeoLite2-Country.

`KEEPPAM_TRUSTED_PROXIES` — CIDR, для которых читаются `X-Forwarded-For` / `X-Real-IP`. Пусто = только `RemoteAddr`.

См. `docs/geoip.txt`.

OPA extra deny: `KEEPPAM_OPA_POLICY` — см. `docs/opa.txt`.

## FIPS / SBOM

Поза, не сертификат. См. `docs/fips-sbom.txt`.

- `KEEPPAM_FIPS_REQUIRED=true` — отказ стартовать без boringcrypto / GOFIPS140
- `KEEPPAM_SBOM_FILE` — готовый CycloneDX; иначе runtime `ReadBuildInfo`
- `GET /api/v1/admin/settings/sbom`

Трейсы: `KEEPPAM_OTEL_ENDPOINT` → Collector → Tempo (`docs/otel-collector.txt`, `docs/tempo.txt`). `KEEPPAM_OTEL_ENV` — `deployment.environment`.

## PAdES (compliance PDF)

`KEEPPAM_PDF_CERT_FILE` + `KEEPPAM_PDF_KEY_FILE` — RSA PEM. Опц. `KEEPPAM_PDF_TSA_URL` → B-T; `KEEPPAM_PDF_LTV=true` (+ TSA) → B-LT; `KEEPPAM_PDF_LTA=true` (+ LTV) → B-LTA. См. `docs/pades.txt`. Без пары PDF unsigned.

## Memory hardening

См. `docs/memory.txt`. Linux: нет coredump, `PR_SET_DUMPABLE=0`, `mlock` DEK.

- `KEEPPAM_ALLOW_COREDUMP=true` — отладка (не для prod)
- compose: `cap_add: IPC_LOCK` + `ulimits.memlock: -1`
