# KeepPAM: i18n RU/EN/KK портала

Словарь: `web/src/i18n/catalog.ts` (свой провайдер, без react-i18next). Cookie и localStorage: `kp_lang=kk|en|ru`. По умолчанию — **kk**. Переключатель — на login/setup и в сайдбаре (**KK / EN / RU**).

`Accept-Language` уходит с запросами API (`ru` | `en` | `kk`). Ошибки: `{ error, code }`, UI переводит `errors.<code>` (`te()`), не сырой русский с бэка.

Локаль дат: `ru-RU`, `en-GB`, `kk-KZ`.

## Сценарий DoD (T-15)

Вход → актив (JIT / кворум / четыре глаза) → заявка → connect SSH → сессия → replay / watch — на EN без голых русских строк.

Остальные экраны (Config, Users, Groups, JEA, Compliance, Discovery, Forensic, Analytics, Audit, AttackSim) пока RU.
