# KeepPAM: техспецификация для заказчика

## 1) Что такое KeepPAM

KeepPAM — on-prem платформа управления привилегированным доступом (PAM), которая:
- предоставляет доступ к критичным системам по правилам и согласованию;
- не раскрывает постоянные пароли администраторам;
- записывает и протоколирует все привилегированные действия;
- поддерживает расследование инцидентов и требования аудита.

## 2) Бизнес-задачи, которые решает продукт

- Снижение риска компрометации привилегированных учетных данных.
- Контроль «кто, когда, куда и зачем подключался».
- Временный доступ (JIT) вместо постоянных прав.
- Разделение ответственности (руководитель/ИБ/супервайзер).
- Централизованный аудит, экспорт в SIEM и комплаенс-отчетность.

## 3) Ключевые возможности

### 3.1 Управление доступом
- RBAC/ABAC политики (роль, актив, время, сеть, ticket/reason и др.).
- JIT-запросы доступа с согласованием.
- Сценарии согласования:
  - последовательное (руководитель -> ИБ);
  - кворум N из M (например, 2 из 3).
- Four-eyes (супервайзер перед стартом сессии).
- Break-glass доступ для критичных случаев с усиленным аудитом.

### 3.2 Аутентификация пользователей
- Локальные пользователи.
- LDAP/AD.
- OIDC и SAML.
- RADIUS (PAP).
- MFA: TOTP и WebAuthn.
- Step-up MFA для чувствительных операций.

### 3.3 Интеграции с IdP и IAM
- SCIM 2.0 inbound provisioning (Users/Groups).
- Автоматизация onboarding/offboarding пользователей.

### 3.4 Секреты и учетные записи
- Централизованное хранение учетных данных.
- Checkout/checkin и reveal по правам.
- Ротация секретов.
- Password sync на целевых системах (SSH/AD/LDAP/PostgreSQL/MySQL/MSSQL).

### 3.5 Подключения и протоколы
- SSH.
- RDP/VNC (HTML5 в браузере).
- Native RDP (`.rdp`) в поддерживаемом режиме.
- SQL доступ.
- Kubernetes доступ.
- Telnet.
- TN3270.
- Citrix ICA через SOCKS (MVP).

### 3.6 Контроль и запись сессий
- Запись привилегированных сессий.
- Просмотр/воспроизведение.
- Live watch.
- Принудительное завершение сессии.
- Поиск по событиям и артефактам (forensic).

### 3.7 Аудит и комплаенс
- Непрерывный аудит действий.
- Контроль целостности аудита (цепочки/батчи проверки).
- Экспорт в SIEM (syslog/webhook/Kafka/NATS/OpenSearch).
- Отчеты и сценарии PDF-подписания (PAdES/eIDAS-настройки).

### 3.8 Эксплуатация и надежность
- Health/ready/metrics.
- HA-профили 2+2 и 3+2.
- DR/backup drill практики.
- Offline-поставка и обновление.

## 4) Интерфейс и локализация

- Единый веб-портал администратора и оператора.
- Языки интерфейса: казахский, английский, русский.

## 5) Лицензирование

- Поддержка JSON и ex2 лицензий.
- Fingerprint, загрузка и контроль лимитов активов.
- Управление soft/hard ограничениями по активам.

## 6) Форматы поставки

- On-prem дистрибутив для закрытого контура.
- Развёртывание через Docker Compose или Helm/Kubernetes.

## 7) Важно по текущему срезу

- Citrix реализован как SOCKS/`.ica` транспортный сценарий (MVP).
- Часть расширенных enterprise-возможностей поставляется отдельными модулями/SOW.
