# KeepPAM: WORM recordings + HSM posture

## WORM (recordings)

Immutable object storage через S3 Object Lock при sync записей:

| Env | Значение |
|-----|----------|
| `KEEPPAM_RECORDINGS_BACKEND` | `s3` |
| `KEEPPAM_S3_OBJECT_LOCK_MODE` | `GOVERNANCE` или `COMPLIANCE` |
| `KEEPPAM_S3_OBJECT_LOCK_DAYS` | дней retention (default 90) |

При Put выставляются `x-amz-object-lock-mode` + `retain-until-date`.

- Compliance purge: локальный файл может удалиться, S3 Object Lock → `skipped_worm`.
- Legal hold на session → S3 Legal Hold ON; release → OFF.
- Audit events по-прежнему append-only в Postgres (hash-chain + HMAC-батчи, см. `docs/audit-chain.txt`), purge их не трогает.

## HSM posture (data key)

- `KEEPPAM_DATA_KEY_SOURCE=pkcs11` → PIN-токен или PKCS#11 helper (`docs/pkcs11.txt`)
- `vault` → Transit decrypt DEK (HSM seal Vault снаружи)
- `aws` / `gcp` / `azure` → cloud KMS unwrap DEK (см. `docs/kms.txt`)

## Compliance controls

- `worm_recordings` — pass если backend=s3 и Object Lock mode задан
- `kms_hsm_key` — pass для `vault|aws|gcp|azure|pkcs11`, warn для `file`, fail для `env`

См. также `docs/prod-infra.txt`.
