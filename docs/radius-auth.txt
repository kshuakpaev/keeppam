# KeepPAM: вход администраторов по RADIUS (T-48)

Режим **RADIUS** в Config → Авторизация. По умолчанию PAP `Access-Request` на UDP (порт 1812). EAP/RadSec — см. `docs/radius-eap.txt`.

Это **IdP пароля** для консоли (и SSH-шлюза, если включён тот же режим), не второй фактор. Локальный TOTP остаётся, пока не включён «Не требовать локальный MFA».

## Настройка

| Поле | Смысл |
|------|--------|
| host / host:port | NPS, FreeRADIUS, Cisco ISE |
| shared secret | шифруется `KEEPPAM_DATA_KEY`, write-only |
| NAS-Identifier | default `keeppam` |
| timeout | 1–30 с, default 5 |
| роль по умолчанию | если сервер не прислал Filter-Id |
| auto-provision | создать пользователя при первом Accept |
| skip MFA | как у LDAP |

Переключение в RADIUS без secret/host — ошибка сохранения. Локальный `admin` после смены режима **не** логинится паролем из БД, пока режим снова `local`.

## Filter-Id → роль

В Access-Accept атрибут Filter-Id:

`admin` / `operator` / `auditor` / `security` / `owner`, либо с префиксом `keeppam-` (`keeppam-admin`). Иначе — роль по умолчанию. Смена Filter-Id у уже существующего пользователя роль не меняет.

## DoD

FreeRADIUS/NPS: пользователь Accept → вход в портал; Reject → `invalid credentials`; аудит `user.login.failure` reason=`radius`.

x509 client cert → user: `docs/x509-auth.txt` (`POST /auth/login/cert`, поле `x509_identity`).

## Вне scope

RADIUS accounting, CoA. EAP-TLS (только client cert) — см. `docs/x509-auth.txt`.
