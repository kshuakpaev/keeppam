# KeepPAM: DLP-каналы утечки

Контроль выгрузки файлов и данных внутри PAM-сессии. Не отдельный DLP-продукт: запрет каналов на шлюзе + аудит.

## SSH

Запрещено **по умолчанию** (`file_transfer=deny` на Policy/ACL). Режимы **audit** / **capture** — `docs/file-transfer.txt`.

| Канал | Поведение |
|-------|-----------|
| `scp` exec (legacy `-t`/`-f`) | deny / прокси+аудит / прокси+хранение |
| subsystem `sftp` | то же |
| `rsync` exec | всегда deny |
| `scp`/`sftp`/`rsync` в интерактивном PTY | всегда deny (не перехватывается) |
| каналы `forwarded-tcpip`, `x11`, `tun@openssh.com` | `ssh.Prohibited` + аудит |
| `direct-tcpip` | пустой `allowed_egress` — deny (как DLP); иначе allowlist назначений, см. `docs/network-pam.txt` |
| global/session `tcpip-forward`, `x11-req` | отказ + аудит |

Интерактивный `shell` / `pty-req`: line-buffer включается при command pack **или** `max_risk > 0` на ACL (`docs/command-risk.txt`). Если pack есть, `scp`/`sftp`/`rsync` в шелле запрещены DLP даже когда pack их разрешает. Событие сессии: `dlp`.

## SQL

`COPY` / `LOAD` / `INTO OUTFILE` / `INTO DUMPFILE` запрещены всегда (Web SQL и native wire), даже без SQL-пакета. Аудит `session.sql.denied`.

На пакете (`sql_policy_packs`, миграция `044`):

| Поле | Смысл |
|------|--------|
| `max_rows` | лимит строк результата, 1…100000, default 500 |
| `dlp_action` | `truncate` — обрезать; `deny` — не возвращать строки, ошибка DLP |

Без пакета: truncate на 500 строк.

Колонки `mask_columns` — маска по имени колонки, не по содержимому.

## PII в содержимом (узкий)

На ACL / Policy поле `pii_action`: пусто = выкл., `mask`, `deny`. Overlay как у egress: пустое на ACL берётся из Policy. Снимок на connect. Admin bypass (`users.write`) пропускает.

Встроенные паттерны:

| Kind | Что |
|------|-----|
| `email` | адрес |
| `pan` | карта 13–19 цифр + Luhn (Visa/MC/MIR/Amex) |
| `phone` | `+` / `8` и 11–15 цифр |
| `snils` | `XXX-XXX-XXX XX` |

**Свои regex** на именованной Policy (`dlp_patterns`, миграция `071`): до 16 правил, имя `[a-z][a-z0-9_]{0,31}`, RE2. UI: JEA → Policy → textarea «имя regex». Kind в audit = имя правила.

Где: ячейки SQL (web-консоль и native wire); тело HTTPS reverse-proxy; **SSH stdout** (индекс `output`); **keystroke** RDP/VNC (guac); **screen_text** OCR. RDP / k8s body — нет.

Аудит: `session.dlp.masked` / `session.dlp.denied` (только kinds) — SQL, HTTPS, native wire. **SSH stdout / keystroke / OCR:** событие `dlp` при индексе (`via`: `ssh_stdout`, `keystroke`, `screen_text`).

Миграции `065`, `071`. UI: карточка актива и JEA → Policy.

## RDP / VNC (Guacamole)

Для `rdp`: `disable-copy=true`, `enable-drive=false`, `enable-printing=false` (clipboard/drive/printer). Для `vnc`: `disable-copy=true`. USB не пробрасывается.

## Forensic

Тип `dlp` входит в поиск по умолчанию (Сессии → События). Фильтр `type=dlp`.

## Вне scope

Полноценный классификатор PII/NLP, clipboard RDP без guacd, интерактивный scp без JEA-пакета, live PII в stdout до индекса.
