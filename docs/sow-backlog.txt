# KeepPAM: бэклог SOW / OEM (после mid-market)

Базовый mid-market закрыт в ветке `feature/jit-quorum` (MR → `master`).
Ниже — **отдельные коммерческие модули**. Не включать в базовую цену без явного SOW.

Источник: `docs/kp.txt` уровень C, `docs/main22-plan.txt` §9.

## Как брать в работу

1. Заказчик выбирает модуль(и) и DoD.
2. В чате/задаче: «SOW: &lt;id&gt;» (например `SOW-CITRIX-HDX`).
3. Исполнитель оценивает недели и зависимости OEM/партнёр.
4. Acceptance — приложение к модулю (не заменяет `docs/kp-acceptance.txt` пилота A).

## Черновик DoD (коротко)

### SOW-CITRIX-HDX
- Terminate HDX на шлюзе KeepPAM; STA ticket flow; StoreFront broker (или документированный subset).
- Запись/replay экрана ICA на уровне, согласованном с OEM.
- Acceptance: сессия через StoreFront → запись → forensic hit.
- **Статус:** фазы 1–4 в коде (plugin terminate + recording/OCR ingest + mock); пиксельный ICA decode — OEM binary.

### SOW-GEO-HA
- Два сайта; async репликация метаданных (+ политика RPO/RGO).
- Failover runbook; split-brain fencing согласован с PG.
- Acceptance: kill site A — login/JIT на site B в SLA.
- **Статус:** фазы 1–4 закрыты (witness/split-brain); см. `docs/geo-ha.txt`.

### SOW-ORACLE
- Rotate/sync пароля Oracle УЗ из KeepPAM vault.
- Thick-client path или явный out-of-scope в SOW.
- Acceptance: rotate → connect SQL*Plus/app с новым секретом без показа оператору.
- **Статус:** закрыт (thin go-ora + SQL*Plus SSH fallback); wire SQL*Net — out of scope.

### SOW-RADIUS-EAP
- EAP-TTLS или PEAP (указать в SOW); опционально RadSec.
- Map Filter-Id/групп → роль как у PAP.
- Acceptance: тестовый FreeRADIUS EAP → portal login.
- **Статус:** закрыт (EAP-TTLS inner PAP, PEAP MSCHAPv2, optional RadSec).

### SOW-RDP-FILE
- Файл из RDP clipboard/drive redirection в storage + replay download (как SCP capture).
- Default deny; policy enable.
- Acceptance: copy file in RDP → artifact SHA совпадает.
- **Статус:** закрыт (guacd staging + ingest на end session).

### SOW-NLP-DLP
- Keyword/phrase classifier контента (credentials, financial, legal, custom rules).
- `nlp_dlp_action` audit/mask/deny; те же каналы что PII DLP.
- Acceptance: audit hit на «salary»; deny на CONFIDENTIAL/NDA.
- **Статус:** закрыт (on-prem, без ML-моделей).

### SOW-NAC
- REST NAC client: pre_connect posture + session_start/end notify.
- Modes audit/enforce; mock `cmd/nac-mock` для acceptance.
- Acceptance: enforce блокирует IP *.66; audit логирует без блокировки.
- **Статус:** закрыт (не VLAN controller; CoA out of scope).

### SOW-EIDAS
- Qualified gate на compliance PDF: eIDAS QES / ФСТЭК КЭП policy OID.
- PAdES-B-LTA + optional PKCS#11 HSM для ключа подписи.
- Acceptance: qualified cert + mode=qualified → PDF export с QES label; без OID → блок.
- **Статус:** закрыт (on-prem OID check + helper; QTSP/OEM — партнёр).

### SOW-UEBA-ML
- Peer-group baseline (`user_groups`), composite ML score, live mid-session guac scan.
- Factors: `ueba_peer_outlier`, `ueba_ml_high`, `ueba_live_fast`.
- Acceptance: rare asset → peer outlier; live RDP bot typing → mid-session notify.
- **Статус:** закрыт (weighted on-prem model, no external ML runtime).

### SOW-WINRM-DISC
- WinRM discovery локальных privileged users на Windows RDP-активах (5985/5986).
- Fallback SAM через SSH (`net user` / administrators group).
- Import кандидата → vault account без секрета.
- Acceptance: RDP asset + WinRM → Administrator в кандидатах; WinRM down + SSH :22 → SAM fallback.
- **Статус:** закрыт (`winrm_accounts`, migration 103); см. `docs/winrm-discovery.txt`.
