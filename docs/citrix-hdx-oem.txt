# KeepPAM: OEM HDX terminate + recording plugin contract (SOW-CITRIX-HDX phases 3–4)

KeepPAM **does not** decode Citrix HDX/ICA. The OEM plugin terminates HDX, injects vault
credentials, and pushes recording/OCR metadata into KeepPAM.

## Enable

```bash
go run ./services/auth/cmd/citrix-hdx-mock   # :14950

export KEEPPAM_CITRIX_HDX_PLUGIN_URL=http://127.0.0.1:14950
export KEEPPAM_CITRIX_HDX_CALLBACK_BASE=http://127.0.0.1:8080   # or KEEPPAM_PUBLIC_URL / CORSOrigin
# asset.citrix_transport = hdx
```

| API | Auth | Purpose |
|-----|------|---------|
| `GET /api/v1/admin/citrix/hdx/health` | `assets.read` | plugin health |
| `POST /api/v1/citrix/hdx/ingest` | Bearer ingest token | plugin → JSONL + forensic events |
| `POST /api/v1/admin/sessions/{id}/citrix/hdx/sync` | `sessions.write` | pull Status.events |

## Plugin HTTP API

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/healthz` | `{status,capabilities,vendor,version}` — prefer `record`,`ocr` |
| POST | `/v1/sessions` | start terminate (+ optional record) |
| GET | `/v1/sessions/{id}` | status + `events[]` |
| DELETE | `/v1/sessions/{id}` | stop |

### POST /v1/sessions body (extra phase 4 fields)

```json
{
  "keeppam_session_id": "uuid",
  "vda_host": "vda.corp",
  "vda_port": 1494,
  "username": "ops",
  "password": "…",
  "recording_hint": "/data/recordings/citrix/….jsonl",
  "callback_url": "https://pam/api/v1/citrix/hdx/ingest",
  "ingest_token": "…",
  "record": true
}
```

### Recording events (`events[]` / ingest body)

```json
{
  "events": [
    {"t":"…","event":"hdx_frame","seq":2,"meta":{"w":1280,"h":720,"offset":0.5}},
    {"t":"…","event":"hdx_ocr","seq":3,"meta":{"text":"Password","offset":0.6}},
    {"t":"…","event":"hdx_keystroke","seq":4,"meta":{"line":"whoami","offset":1.2}},
    {"t":"…","event":"hdx_ended","seq":9,"meta":{}}
  ]
}
```

`seq` is used for dedup. KeepPAM writes JSONL under `recordings/citrix/{session}.jsonl` and
stores `screen_text` / `keystroke` with `source=hdx` for transcript + OCR search.

On session end KeepPAM: sync Status → Finalize (stop plugin) → `castindex` Index/OCR.

## Transport matrix

| `citrix_transport` | Behaviour |
|--------------------|-----------|
| `socks` / `hdx_pending` | SOCKS + `.ica` |
| `hdx` | plugin terminate + record path |

## Out of scope (real OEM binary)

CGP/HDX decode, EDT/UDP, pixel video / MP4 export of ICA frames.
