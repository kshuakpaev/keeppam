# KeepPAM: OCR кадра RDP/VNC

**Не** полное видео и не live OCR. После сессии guacenc выбирает кадры с интервалом из Policy, Tesseract (`rus+eng` по умолчанию) → `session_events` тип **`screen_text`**.

Отдельно от клавиш opcode `key` (`docs/session-search.txt`).

## Pipeline

1. `.guac` → guacenc → `.m4v` / `.mp4` (как MP4 export).
2. `POST http://guacenc:8099/ocr` `{"path","max_frames","interval_sec","lang"}`.
3. ffmpeg: кадр на timestamp; tesseract `--psm 6` `-l rus+eng`.
4. API: `castindex.IndexOCR` → payload `{line, source:"guacenc", offset}`.

Авто: `IndexOCRAsync` при конце RDP/VNC/isolated (timeout 15 мин). Клавиши — отдельно, 30 с.

Параметры берутся из снимка Policy сессии (`ocr_lang`, `ocr_interval_sec`, `ocr_max_frames`). Без Policy — `rus+eng`, 15 с, до 60 кадров.

## Лимиты

| | Default | Max |
|-|---------|-----|
| Интервал | 15 с | 5–120 с |
| Кадров | 60 | 120 |
| Символов / кадр (Python) | 4000 | |
| Строка события | ≤ 512 рун | |
| Пустые / дубли подряд | skip | |

## API / UI

`GET .../transcript` — `screen_text[]`.  
`POST .../transcript` `{force?, ocr?}` — `ocr:true` синхронно запускает OCR (может занять минуты).

JEA → named Policy: язык OCR, интервал, макс. кадров.

Forensic: `type=screen_text`. Replay RDP/VNC: **OCR экрана**.

Контейнер `guacenc`: `tesseract-ocr-eng` + `tesseract-ocr-rus`. Пересборка образа после смены Dockerfile.

## Вне scope

Полный текст каждого кадра, live OCR, OCR SSH stdout, compliance-отчёт, маскирование паролей на экране.
