# KeepPAM: SOW-CITRIX-HDX

Модуль уровня C. Базовый mid-market уже даёт Citrix **SOCKS + `.ica`** (`docs/citrix-socks.txt`).
Этот SOW закрывает путь к HDX terminate / STA / StoreFront / записи экрана.

## Фазы

| Фаза | Содержание | Статус |
|------|------------|--------|
| **1** | Asset metadata; KeepPAM STA ticket; richer `.ica`; SOCKS bytes; JSON validate | **есть** |
| **2** | CtxSta.dll CGI; probe внешних STA; StoreFront discovery + resources (read-only) | **есть** |
| **3** | HDX/ICA **terminate** на шлюзе (OEM binary / partner stack) | OEM |
| **4** | Запись экрана ICA → replay / forensic / OCR | OEM + storage |

## Phase 1 DoD

- [x] Миграция `094_citrix_hdx.sql`
- [x] Поля актива + STA ticket в `.ica` + JSONL bytes
- [x] `GET /api/v1/citrix/sta/{ticket}`
- [x] UI полей Citrix

## Phase 2 DoD

- [x] `GET /Scripts/CtxSta.dll?ticket=` и `/citrix/Scripts/CtxSta.dll?ticket=` → text/plain (совместимость Workspace)
- [x] `POST /api/v1/admin/assets/{id}/citrix/sta/probe` — опрос внешних STA из `citrix_sta_urls`
- [x] `GET /api/v1/admin/assets/{id}/citrix/discovery` — StoreFront discovery
- [x] `GET /api/v1/admin/assets/{id}/citrix/resources` — enum published apps (Basic auth от учётки актива)
- [x] Клиент `internal/citrix/storefront.go` + STA CGI helpers
- [x] Docs / UI кнопка enum

`citrix_transport=hdx_pending` — маркер «ждём OEM»; трафик по-прежнему SOCKS.

## Phase 3+ (OEM)

- Decode HDX / CGP на KeepPAM, vault inject без SOCKS
- Screen recording как у RDP `.guac`
- Полный StoreFront launch ICA от SF (write path)

## Acceptance

1. Session → `.ica` + STA ticket; `GET /Scripts/CtxSta.dll?ticket=…` → 200 text/plain.
2. StoreFront URL на активе → `…/citrix/resources` возвращает список (или явная ошибка HTTP от SF).
3. Workspace через SOCKS → connect/disconnect JSONL.
4. (фаза 3+) HDX terminate → forensic — **OEM**.
