# KeepPAM: SOW-CITRIX-HDX

Модуль уровня C. Базовый mid-market уже даёт Citrix **SOCKS + `.ica`** (`docs/citrix-socks.txt`).
Этот SOW закрывает путь к HDX terminate / STA / StoreFront / записи экрана.

## Фазы

| Фаза | Содержание | Статус |
|------|------------|--------|
| **1** | Asset metadata (published app, StoreFront URL, STA URLs, transport); KeepPAM **STA ticket stub**; richer `.ica`; SOCKS bytes + disconnect events; `GET /api/v1/citrix/sta/{ticket}` | **есть (срез)** |
| **2** | Реальный STA CGI / ticket redeem с Citrix Delivery Controller; StoreFront resource enumeration (read-only broker) | план |
| **3** | HDX/ICA **terminate** на шлюзе (OEM binary / partner stack) | OEM |
| **4** | Запись экрана ICA → replay / forensic / OCR | OEM + storage |

## Acceptance (модуль)

1. Актив citrix с published app → session → `.ica` содержит `InitialProgram` и `STATicket`.
2. `GET /api/v1/citrix/sta/{ticket}` → 200 + session_id.
3. Workspace через SOCKS → connect + disconnect в recording JSONL с байтами.
4. (фаза 3+) StoreFront → HDX terminate → forensic hit по кадру — **OEM**.
