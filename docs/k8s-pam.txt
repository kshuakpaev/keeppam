# KeepPAM: K8s PAM

## Phase 1 — lease (vault checkout)

Короткий lease kubeconfig / SA token из vault без proxy.

1. Актив: `asset_type=k8s`, `protocol=kubectl`, address = API server, port 6443.
2. Учётка: `auth_method=kubeconfig|sa_token`, секрет в `secret_enc`.
3. `POST /api/v1/admin/assets/{id}/k8s/access` — policy + ITSM → lease TTL 15m, secret один раз.
4. `POST /api/v1/admin/k8s/leases/{id}/consume`.
5. Аудит: `k8s.access.granted` / `denied` / `k8s.lease.consumed` **без тела секрета**.

UI: **Vault checkout** (вторичная кнопка).

Если на учётке включён TokenRequest — lease отдаёт ephemeral JWT (или kubeconfig с ним), не vault-секрет. TTL lease ≤ TTL токена.

## Phase 1.5 — TokenRequest

Короткий SA-токен через Kubernetes TokenRequest API. Vault хранит privileged kubeconfig / SA, который умеет `create token` на целевой SA.

На учётке:

| Поле | Смысл |
|------|--------|
| `token_request_enabled` | mint вместо выдачи vault |
| `k8s_sa_namespace` | пусто → `default` |
| `k8s_sa_name` | пусто → `username` учётки |
| `token_ttl_seconds` | 60–86400, default 900 |

`POST /api/v1/namespaces/{ns}/serviceaccounts/{sa}/token` с vault Bearer (или client cert). Ошибка mint → отказ lease/proxy, **без** fallback на privileged секрет.

Proxy (`:16443`) подставляет ephemeral token upstream и перевыпускает за 30с до истечения. Клиентский kubeconfig по-прежнему `{session}.{wire}` на PAM.

Аудит: `k8s.access.granted` (`auth_mode=token_request`, ns/sa/ttl, без JWT), `session.k8s.token_requested`.

Checkout/Reveal по-прежнему показывает vault-секрет (`assets.write`).

## Phase 2 — kubectl proxy

Сессия через PAM: клиент ходит на `:16443`, PAM расшифровывает vault и проксирует API server.

1. `POST /api/v1/admin/sessions` protocol=`kubectl` — policy + ITSM + break-glass/admin bypass.
2. Ответ / `GET .../sessions/{id}/kubeconfig` — **переписанный** kubeconfig (server=PAM, token=`{session}.{wire}`). Vault SA **не** отдаётся.
3. TLS listener `KEEPPAM_K8S_API_ADDR` (default `:16443`), self-signed в `KEEPPAM_K8S_TLS_PATH`.
4. Аудит `session.k8s` + NDJSON `{recordings}/k8s/{id}.jsonl`: verb/resource/namespace/name/status, `body_redacted`.
5. Deny: exec / attach / port-forward / HTTP Upgrade. Impersonate-заголовки клиента снимаются.

```bash
export KUBECONFIG=./keeppam-xxxxxxxx.kubeconfig
kubectl get ns
```

Публичный URL: `KEEPPAM_K8S_PUBLIC_URL` (стенд: `https://localhost:16443`).

## Вне scope

- in-cluster RBAC / namespace ACL / impersonation PAM-пользователя
- auto-rotate SA / TokenRequest bound to PAM user
- kubectl в браузере / запись тел Secret
