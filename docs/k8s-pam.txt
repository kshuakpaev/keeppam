# KeepPAM: K8s PAM lite

## Что есть

Короткий lease kubeconfig / SA token из vault без kubectl-proxy.

1. Актив: `asset_type=k8s`, `protocol=kubectl`, address = API server, port 6443.
2. Учётка: `auth_method=kubeconfig|sa_token`, секрет в `secret_enc`.
3. `POST /api/v1/admin/assets/{id}/k8s/access` — policy + ITSM (если включён) → lease TTL 15m, secret один раз в ответе.
4. `POST /api/v1/admin/k8s/leases/{id}/consume` — пометить lease использованным.
5. Аудит: `k8s.access.granted` / `denied` / `k8s.lease.consumed` **без тела секрета**.

## UI

Активы → тип k8s → протокол kubectl. Добавить учётку с kubeconfig YAML или token. Кнопка **«Получить kubeconfig»** → modal: copy / download / consume.

## Вне scope

- kubectl/API proxy через PAM
- in-cluster RBAC / namespace ACL со стороны PAM
- эфемерные TokenRequest / auto-rotate SA
- запись kubectl-команд
