# Native RDP + redirection policy (КП-2.6 / T-27 / T-29)

Два профиля: **DLP-strict** (default) и **full** (clipboard/drive/printer по политике). Native mstsc — опция.

## T-27 — буфер / диски / принтеры (HTML5 Guacamole)

В Access Policy (JEA → Policy):

| Флаг | Default | Guacamole |
|------|---------|-----------|
| `rdp_clipboard` | off | `disable-copy` / `disable-paste` |
| `rdp_drive` | off | `enable-drive` + `recordings/rdp-drive/{session}`; ingest при `file_transfer=audit|capture` |
| `rdp_clipboard` | off | clip on; staging `KeepPAMClip` при capture без drive — `docs/rdp-file-capture.txt` |
| `rdp_printer` | off | `enable-printing` |

Snapshot замораживается при create session. Включение = явное исключение из DLP (`docs/dlp.txt`).

HTML5-клиент (`DesktopSession`): при `policy_snapshot.rdp_clipboard` — remote→browser через `onclipboard`; browser→remote через событие `paste` (Ctrl+V не preventDefault’ится) → `createClipboardStream` + Ctrl+V на remote. Без флага UI показывает «выключен политикой».

Миграция `085_rdp_policy.sql`.

## T-29 — native mstsc path

1. Broker: `KEEPPAM_RDP_PUBLIC_HOST` задан (пусто/`off` = выкл.). Policy `rdp_native` **или** `KEEPPAM_RDP_NATIVE_DEFAULT=true` (default) — mstsc без обязательной галки в JEA.
2. Env:
   - `KEEPPAM_RDP_PUBLIC_HOST` — hostname в `.rdp`.
   - `KEEPPAM_RDP_JUMP_IMAGE` — образ jump (`keeppam-rdp-jump:local`; `off` = не использовать). Один логин на цель: Xvfb + xfreerdp, mstsc → xrdp, guacd пишет `.guac`.
   - `KEEPPAM_RDP_PROXY_BIN` — запасной `freerdp-proxy` (если jump недоступен).
   - `KEEPPAM_RDP_PROXY_CERT_FILE` / `_KEY_FILE` — опционально (иначе TLS API).
   - `KEEPPAM_RDP_NATIVE_DEFAULT=false` — снова требовать галку `rdp_native` (HTML5-only при политике off).
3. Create session → `rdp_token`, `rdp_file`, `rdp_addr`; UI скачивает `.rdp`. Ежедневная работа — mstsc, не браузер.
4. Предпочтительно: broker поднимает **per-session rdp-jump** (docker). xfreerdp на jump логинится на цель с vault-учёткой; mstsc без пароля цели (NLA к jump отключён в `.rdp`).
5. Download: `GET /api/v1/admin/sessions/{id}/rdp.rdp`.

Каналы cliprdr/rdpdr: на jump — `/drive:KeepPAM` и clipboard xfreerdp по тем же флагам политики. Файлы на диске KeepPAM индексируются `IngestRDPSession` как HTML5.

## Ограничения

- Replay native через jump — тот же HTML5-плеер `.guac` (MP4/OCR как у браузерных сессий).
- Без jump-образа: запасной **SessionCapture** freerdp-proxy → `recordings/rdp-native/{id}/` (pcap/PDU, не плеер). FreeRDP 3.x секцию может проигнорировать.
- Без jump и без proxy bin: `.rdp` прямо на актив — записи на PAM нет.
- freerdp-proxy module API / RD Gateway SSO — вне среза.
- Citrix — КП-3 SOCKS MVP (`docs/citrix-socks.txt`); HDX — SOW.
- RDS RemoteApp — `docs/remoteapp.txt` (поля актива → guac / `.rdp` / jump `REMOTE_APP`).

## DoD

- DLP-strict: clipboard/drive/printer off в HTML5.
- Full: флаги on → redirect в guac / jump drive.
- mstsc → KeepPAM (rdp-jump или freerdp-proxy) → target без пароля в клиенте при broker (`KEEPPAM_RDP_PUBLIC_HOST`). Галку `rdp_native` для новых политик не требуется (`KEEPPAM_RDP_NATIVE_DEFAULT`).
- Native jump: `.guac` в `recordings/guac/{id}`, `recording_path` с create; replay открывается в портале.
