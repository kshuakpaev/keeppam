# KeepPAM: единый дистрибутив (P0.5 / T-01 compose)

Версия: файл `VERSION` (semver). При `./scripts/keeppam-dist.sh` / `make dist` patch увеличивается автоматически (+0.0.1), история — `VERSION_HISTORY`.

**Virtual Appliance (OVA / Hyper-V):** `docs/appliance-ova.txt` (КП-2.1 / T-01 P5 + T-02).

**Системные требования** (минимум / оптимум / расширенный): `docs/system-requirements.txt`.

## Сборка артефакта (рекомендуется)

Один скрипт: bump VERSION → бинарники API/UI → Docker-образы → `tar.gz` для другого сервера.

```bash
./scripts/keeppam-dist.sh
# или:
make dist

# полный стенд (Grafana / OpenSearch / HAProxy image):
SET=full ./scripts/keeppam-dist.sh

# управление версией:
BUMP=patch ./scripts/keeppam-dist.sh   # default: 1.0.0 → 1.0.1
BUMP=minor ./scripts/keeppam-dist.sh   # 1.0.1 → 1.1.0
BUMP=major ./scripts/keeppam-dist.sh   # 1.1.0 → 2.0.0
BUMP=none  ./scripts/keeppam-dist.sh   # не менять VERSION
make bump                              # только +patch в VERSION
./scripts/keeppam-version.sh show
```

Результат: `dist/keeppam-<ver>-offline-<set>.tar.gz` (+ `.sha256`, `.README.txt`).

Переменные:

| Переменная | Смысл |
|------------|--------|
| `SET=core\|full` | состав образов (default `core`) |
| `OUT=…` | каталог вывода (default `dist/`) |
| `BUMP=patch\|minor\|major\|none` | автосчётчик версии (default `patch`) |
| `SKIP_BUILD=1` | только упаковать уже собранные образы |
| `SKIP_PULL=1` | не тянуть отсутствующие upstream-образы |

Только упаковка (образы уже локально, как после `make up`):

```bash
SET=core ./scripts/keeppam-pack.sh
SET=full ./scripts/keeppam-pack.sh
```

В архиве: `images.tar` (`docker save`) + compose + миграции + `auth-server` + скрипты install/upgrade/rollback + `NOTICE`.

## Установка с USB (без git, без registry)

```bash
tar -xzf keeppam-1.0.0-offline-core.tar.gz
cd keeppam-1.0.0-offline-core
./install.sh
```

Скрипт: `sha256sum` → `docker load` → `deploy/.env` из `.env.example` → достаёт `auth-server` из образа, если файла нет → `docker compose up -d --pull never --no-build` → ждёт `GET /readyz`.

Исходящего pull нет. Смените `KEEPPAM_BOOTSTRAP_ADMIN_PASSWORD` в `deploy/.env`.

HA:

```bash
KEEPPAM_HA=1 ./install.sh          # 2+2
KEEPPAM_HA=3 ./install.sh          # 3 control + 2 worker
```

Наблюдаемость (профиль `obs`): автоматически для `SET=full`, иначе:

```bash
KEEPPAM_OBS=1 ./install.sh
```

Из git checkout (образы уже в local Docker):

```bash
./scripts/keeppam-install.sh
# или с бандлом:
./scripts/keeppam-install.sh /media/usb/keeppam-1.0.0-offline-core.tar.gz
```

Портал: http://127.0.0.1:5173 (логин bootstrap из `.env`).

Демо 45 мин: `docs/demo-45min.txt`, `./scripts/demo-seed.sh`.

Обновление той же площадки: `docs/offline-update.txt`.
