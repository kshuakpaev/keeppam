# KeepPAM: Observability / SLO

## Что есть

In-process метрики + снимок SLO + Prometheus / Alertmanager / Grafana / Tempo на стенде.

1. `GET /metrics` — Prometheus text 0.0.4, без auth (как `/healthz`).
2. `GET /api/v1/admin/analytics/slo` — JSON для UI, право `audit.read`.
3. Карточка **SLO** на странице Аналитика.
4. Compose: Prometheus `:9090`, Alertmanager `:9093`, Grafana `:3001`, Tempo `:3200`.
5. `POST /api/v1/alerts/webhook` — Alertmanager → inbox (`audit.read`) + аудит `obs.alert`. Bearer `KEEPPAM_ALERT_WEBHOOK_TOKEN` (пусто = webhook выключен).
6. OpenTelemetry traces: HTTP spans API + `ssh.session` на worker → OTLP HTTP через Collector (`docs/otel-collector.txt`). `/healthz`, `/metrics` и WebSocket не трейсятся. Тела и секреты в spans не пишутся.

Стенд:

- Grafana: http://localhost:3001 (anonymous Viewer; admin / `ChangeMeNow!1`) — Prometheus + Tempo
- Prometheus: http://localhost:9090
- Alertmanager: http://localhost:9093
- Tempo: http://localhost:3200 (`keeppam-api` / `keeppam-ssh`, Explore в Grafana)
- Collector: внутри compose `otel-collector:4318` (`docs/otel-collector.txt`)
- API/worker: `KEEPPAM_OTEL_ENDPOINT=http://otel-collector:4318`

## Цели (константы, не settings)

| Сигнал | Target |
|--------|--------|
| auth p95 (handler login/MFA/WebAuthn/OIDC/SAML) | 500ms |
| session setup p95 (`started_at - created_at`, 24ч) | 2s |
| SIEM export lag (если SIEM включён) | 60s |

Burn = observed / target. `breached` если любой burn > 1. Нет сэмплов → не breach.

UI p95 — кольцо в процессе API + SQL за 24ч. Grafana p95 — `histogram_quantile` по scrape (5m). Это разные окна.

## Алерты Prometheus

Файл `deploy/prometheus/rules/keeppam.yml`:

| Alert | Условие |
|-------|---------|
| KeepPAMAPIDown | scrape `up==0` 1m |
| KeepPAMAuthP95High | p95 auth > 500ms, 10m |
| KeepPAMSessionSetupP95High | p95 setup > 2s, 10m |
| KeepPAMSIEMLagHigh | lag > 60s, 5m |
| KeepPAMHTTP5xx | доля 5xx > 5%, 5m |
| KeepPAMSessionSpike | active sessions > 50, 5m (лаб) |
| KeepPAMSessionHigh | active sessions > 800, 5m (NIT §4) |
| KeepPAMSessionCapacity | active sessions > 950, 2m |

## Метрики `/metrics`

- `keeppam_http_requests_total{route,code}`
- `keeppam_http_request_duration_seconds{route}`
- `keeppam_auth_login_seconds{method}`
- `keeppam_session_setup_seconds` (API-процесс; SSH worker — в SQL p95)
- `keeppam_audit_events_total`
- `keeppam_active_sessions`
- `keeppam_audit_export_lag_seconds`

## Вне scope

- spans на SQL/Redis/k8s upstream
- OpenTelemetry Collector (fan-out)
- хранение гистограмм в Postgres
- отдельные SLO settings
