# KeepPAM: многоступенчатый JIT

Default: один этап `manager` — как раньше (любой с `access.approve`).

PROD / чувствительные активы: на карточке **Руководитель + ИБ**.

```
Request
  → Manager (access.approve)
  → Security (access.approve.security)
  → JIT binding
```

Снимок `approval_stages` пишется в заявку при создании (смена настройки актива не ломает уже открытый запрос).

Один человек не одобряет свою заявку и не закрывает два этапа. Deny — на текущем этапе, своим правом.

Миграция `045`. Роль `security` для второго этапа.
